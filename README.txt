RYUHUU STORE — PRODUK SATUAN + DOCK + KERANJANG INDEX

CARA PASANG
Ekstrak dan upload SEMUA isi ZIP ke root website. Pertahankan susunan folder, termasuk assets/ dan produk/. Buat backup website sebelum menimpa file.
Buka daftar-link.html atau daftar-link.txt untuk daftar link produk yang dapat dibagikan.

ISI PAKET
- produk/: 81 halaman (75 nama file lama + 6 halaman baru).
- index.html: desain index terbaru, dengan adapter keranjang bersama.
- keranjang.html: menggunakan struktur keranjang dan checkout dari index.html.
- assets/: wallpaper Ryo, tema produk, dock responsif, adapter data keranjang.
- QRIS.png: gambar QRIS asli.

DOCK BAWAH
Mengikuti index: scroll turun mengecil dan menyembunyikan label; scroll naik membesar dan menampilkan label. Berlaku pada desktop dan ponsel. Pada checkout, dock menggunakan Data / Metode / Ringkasan / Kontak / Toko seperti index.

INFORMASI DAN HARGA
Deskripsi, fitur, daftar game, dan bonus asli pada 75 halaman lama dipertahankan. Slash tetap Multi-Game, termasuk fitur WuWa/SLA, game lainnya, dan bonus Gratis Bypass Genshin Tools.
Harga/paket tetap mengikuti katalog index terbaru. Lotus dihentikan/gratis; Private B VIP dihentikan. Hooked Valorant dan Kinu ZZZ perlu konfirmasi admin karena tidak ada dalam katalog terbaru.
Private B (Solo Leveling Arise) dan Private S (Valorant) dibeli melalui DM admin; Rp 0 bukan harga jual.
Kupon mengikuti index: DISKONKIKIR26 = 5%.

KERANJANG BERSAMA
Halaman produk, index, dan keranjang berbagi data ryuhuu_cart_v2. Adapter memigrasikan data cart lama satu kali, menjaga kontak, dan mencegah item yang sudah dihapus muncul kembali. Jumlah item dan harga terbaru disinkronkan antarlaman pada origin website yang sama.
Tombol Checkout dari halaman produk membuka checkout; ikon Cart membuka keranjang untuk meninjau/mengubah jumlah item.
Pilihan bahasa/region tetap mengikuti persetujuan pengguna seperti index; tidak dipilihkan otomatis.

CATATAN
Pembayaran manual tetap memerlukan verifikasi admin. Tidak ada backend pembayaran baru atau transaksi otomatis yang ditambahkan.
Font, ikon, Tailwind, dan jsPDF menggunakan CDN seperti index asli dan membutuhkan internet.
Aset branding/favicon serta sw.js yang sudah ada pada website dapat tetap dipakai. Jika sw.js tidak tersedia, halaman tetap berfungsi tanpa service worker.
